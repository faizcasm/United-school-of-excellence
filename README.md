# United School of Excellence website

A responsive Next.js 15 starter website for United School of Excellence, Hyderbeigh, Pattan.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

This is a designed starter using only the facts currently verified publicly:
- School name: United School of Excellence
- Location: Hyderbeigh, Pattan, Baramulla, Jammu & Kashmir

Replace the clearly marked unconfirmed contact details and verify all school-specific claims with the school management. In particular, obtain confirmation for:
- Official phone number, email and exact campus address / map pin
- Classes and age groups offered
- Recognition / affiliation and registration details
- Medium of instruction
- Admission dates, eligibility, documents and fee information
- Principal / head of institution and approved school history
- Facilities, transport, extracurricular activities and achievements
- Approved school logo, campus photographs and student-photo permissions

The education-principles section is proposed website copy, not a verified statement of the school's formal policy. Stock photographs are used as temporary design imagery and must be replaced with approved school photographs before launch.

The admissions flow currently directs visitors to the contact section. No database, authentication, CMS or working submission backend is included.
